# NZ Constitutional Restoration

An open-access archive for research on New Zealand constitutional history, common law foundations, Māori history, colonial administration, and modern governance. The repository preserves the Master Edition and provides a stable home for related research and supplementary material.

## Archive contents

- [Master Edition (PDF)](NEW%20ZEALAND%20CONSTITUIONAL%20HISTORY,%20COMMON%20LAW%20%20AND%20RESTORATION.pdf) is preserved at the repository root to keep its existing URL stable.
- [metadata.json](metadata.json) records the project, edition, archive record, and license in machine-readable form.
- `research/` is for source lists, citations, and research notes.
- `documents/` is for future editions and related documentary material.
- `supplementary/` is for supporting files that do not belong in an edition.

The [Internet Archive record](https://archive.org/details/new-zealand-constituional-history-common-law-and-restoration) provides an additional access point to the Master Edition.

## GitHub Pages

The `Deploy to GitHub Pages` workflow publishes the repository root whenever changes are pushed to `main` or the workflow is run manually. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
